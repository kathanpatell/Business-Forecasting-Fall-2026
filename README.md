## About This Repository

This repository contains my homework assignments and supporting files for Business Forecasting during the Fall 2026 semester. It will document my work with business data, time-series concepts, data visualization, and forecasting methods using R and RStudio.

Each homework assignment is stored in its own folder so that the source code, finished report, data, and supporting documentation remain together.

## Typical Assignment Files

- **RMD files:** R Markdown source files containing written answers and R code.
- **HTML files:** Finished reports created using the Knit command in RStudio.
- **CSV or Excel files:** Data used for analysis and forecasting practice.
- **README files:** Short explanations of an assignment, its data, and its files when needed.

## Work Covered

Assignments in this repository may include:

- Importing and preparing business data
- Creating summaries and visualizations
- Working with monthly or quarterly time-series data
- Identifying patterns such as trends and seasonality
- Creating and comparing forecasting models
- Evaluating forecast accuracy
- Explaining results in a business context

The repository will be updated as new topics and assignments are completed during the semester.
